# Convertube

**[convertube.net](https://convertube.net)** — free file conversion that runs in your browser. PDF, video, audio and images are converted on your own device; the file is never uploaded.

This repository is Convertube's **public feedback tracker**. The website's source code is not published here.

## Report a problem or request a feature

- **Something went wrong** → [Report a problem](https://github.com/convertube/convertube/issues/new?template=bug.yml)
- **A conversion or feature you want** → [Make a wish](https://github.com/convertube/convertube/issues/new?template=feature.yml)
- **Want the same thing someone already asked for?** Add a 👍 to [their issue](https://github.com/convertube/convertube/issues). We read the votes when deciding what to build next.

You can write in any language. 可以用中文写 · Puedes escribir en español · 日本語でも大丈夫です.

### About files and privacy

Issues here are **public** — anyone can read them. If a problem only happens with a particular file:

1. **Remove anything private** from the file before attaching it, or
2. **Don't attach it** — describe it instead (type, size, where it came from), or
3. **Email it** to [convertubenet@outlook.com](mailto:convertubenet@outlook.com) with your issue number in the subject. Emailed files are used only to reproduce and fix the problem, and are deleted afterwards.

## What Convertube does

| | |
|---|---|
| [PDF converter](https://convertube.net/pdf-converter) | PDF to Word, Excel, JPG, PNG and text; merge, split, rotate, compress; on-device text recognition for scans |
| [Video converter](https://convertube.net/video-converter) | MP4, MOV, MKV, WebM, AVI; video to MP3 or GIF |
| [Audio converter](https://convertube.net/audio-converter) | MP3, WAV, FLAC, AAC, OGG, M4A, Opus, WMA |
| [Image converter](https://convertube.net/image-converter) | JPG, PNG, WebP, HEIC; images to PDF |

All conversion happens in your browser with WebAssembly, so there is no upload wait, no file-size quota from a server, and nothing of yours stored anywhere.
